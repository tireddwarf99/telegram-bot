# Telegram bot

## Запуск

Установите зависимости: `npm install`. Задайте переменные из `.env.example`
в окружении хостинга или локальном `.env`, затем выполните `npm start`.
Основной бот использует `TELEGRAM_API`. Тестовый бот запускается через
`npm test` и использует отдельный `TELEGRAM_API_TEST`.

Запускайте только один экземпляр бота для каждого Telegram-токена:
получение сообщений работает через polling. На хостинге используется
тот же `npm start`; HTTP-проверка доступности — `/health` на порту `PORT`
(по умолчанию 3000).

## TikTok

Бот принимает обычные ссылки `tiktok.com`, а также `tt.site` и `www.tt.site`.
Ссылка может находиться внутри текста сообщения. Для `tt.site` бот сначала
получает обычный адрес публикации из HTTP-перенаправления и передаёт его
в TikWM API.

Если TikWM недоступен или не возвращает медиа, бот использует публичный
сервер [fxTikTok](https://github.com/okdargy/fxTikTok) (`tnktok.com`).
Резервный MP4 скачивается в оперативную память (до 50 МиБ) и отправляется
файлом в Telegram. Хостингу нужен исходящий HTTPS-доступ к Telegram,
TikTok, TikWM, fxTikTok и серверам хранения видео TikTok.
Работа резервного источника зависит от доступности стороннего сервиса.

## Проверки

`npm run test:unit` запускает автоматические тесты без подключения к Telegram
и без загрузки `.env`. `npm test` запускает живого тестового бота.
